# Lab9 — веб-сервис преобразования координат

Автоматизированная система преобразования координат из Excel-файла в отчёт
Markdown и Word. Состоит из бэкенда на FastAPI и фронтенда на Streamlit.

## Архитектура

- **Бэкенд** (`main.py`) — FastAPI-приложение, принимает Excel-файл, преобразует
  координаты по формулам перехода из практической работы №8, возвращает
  отчёт в формате Markdown или Word.
- **Фронтенд** (`app.py`) — Streamlit-приложение, предоставляет пользователю
  интерфейс для загрузки файла, настройки параметров перехода и скачивания
  результата.

## Установка и запуск

Создайте виртуальное окружение и активируйте его:

    python -m venv .venv
    # Windows
    .venv\Scripts\Activate.ps1
    # macOS / Linux
    source .venv/bin/activate

Установите зависимости:

    pip install -r requirements.txt

Установите Pandoc (для экспорта в Word):

    # Windows
    winget install --id JohnMacFarlane.Pandoc
    # macOS
    brew install pandoc
    # Linux
    sudo apt install pandoc

## Запуск

Откройте два терминала.

**Терминал 1 — бэкенд:**

    uvicorn main:app --port 8000

**Терминал 2 — фронтенд:**

    streamlit run app.py

Откройте http://localhost:8501 в браузере.

## Как пользоваться

1. Убедитесь, что боковая панель показывает «Бэкенд доступен».
2. При необходимости измените параметры перехода (dx, dy, dz, wx, wy, wz, m).
3. Загрузите Excel-файл со столбцами Name, X, Y, Z.
4. Выберите формат отчёта — Markdown или Word.
5. Нажмите «Преобразовать».
6. Скачайте готовый отчёт.

## API бэкенда

- **GET /** — информация о сервисе и список эндпоинтов.
- **POST /process-excel/** — принимает Excel, возвращает отчёт в Markdown.
- **POST /process-excel-docx/** — принимает Excel, возвращает отчёт в Word.

Параметры формы (все необязательные, есть значения по умолчанию):
dx, dy, dz, wx, wy, wz, m.

## Формулы преобразования

Прямое преобразование A → B:

    (X_B)         (  1     +wz   -wy )   (X_A)   (dX)
    (Y_B) = (1+m)·( -wz     1    +wx ) · (Y_A) + (dY)
    (Z_B)         ( +wy    -wx    1  )   (Z_A)   (dZ)

где dX, dY, dZ — линейные элементы трансформирования (м);
wx, wy, wz — угловые элементы (рад, переводятся из угловых секунд);
m — масштабный элемент.

## Технологии

- FastAPI, Uvicorn — бэкенд.

- Pandas, OpenPyXL — работа с Excel.
- SymPy — символьные преобразования и LaTeX.
- Pandoc — конвертация Markdown → DOCX.
